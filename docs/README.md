# Mobile Application Developer Portfolio Docs

This folder contains portfolio-level planning and status documentation for the `mobile-app-developer` repository.

Project-specific technical documentation remains inside each application folder so the codebases stay self-contained.

## Portfolio Structure

- `../README.md` — public GitHub portfolio overview
- `../site/` — live portfolio website source
- `../assets/` — README-specific featured-project artwork
- `../glossed-tip/` — Glossed Tip application and project documentation
- `../all-together/` — AllTogether application and project documentation
- `../bite-route/` — Bite Route application and project documentation
- `../.github/workflows/` — path-filtered CI workflows for the three applications
